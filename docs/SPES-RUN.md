# Запуск iOS на телефоне (Redmi Note 11 NFC, `spesn`)

Команды выполняются в обычном терминале из папки репозитория, **без `!` в начале**:

```
cd /home/ruslan/ios-spes
```

## Запуск

1. Подключи телефон по USB.
2. Если телефон работает или завис, держи питание 10–15 секунд, пока экран не погаснет.
3. Сразу зажми **питание + громкость вниз** и держи до экрана FASTBOOT.
4. Запусти:

   ```
   tools/spes-run.sh
   ```

Скрипт дождётся fastboot, загрузит iOS, дождётся SSH и выставит часы. Обычно это занимает минуту-две.
Ничего не прошивается: образ загружается только в память.

Если просто включить телефон, он зайдёт в OrangeFox, а не в iOS. iOS запускается только с компьютера.

## Команды

| Команда | Что делает |
|---|---|
| `tools/spes-run.sh` | Запускает iOS со стандартным образом |
| `tools/spes-run.sh boot ОБРАЗ` | Запускает iOS с другим образом |
| `tools/spes-run.sh ssh` | Открывает командную строку на телефоне |
| `tools/spes-run.sh ssh КОМАНДА` | Выполняет одну команду на телефоне |
| `tools/spes-run.sh time` | Выставляет часы телефона |
| `tools/spes-run.sh log` | Показывает живой журнал ядра, остановка по Ctrl+C |
| `tools/spes-run.sh log ФАЙЛ` | То же, с сохранением в файл |

## Что важно помнить

- **Часы сбрасываются на 1969 год при каждой загрузке.** Скрипт выставляет их сам. Если HTTPS, `apt` или Sileo
  ругаются на сертификаты, выполни `tools/spes-run.sh time`.
- **Перезагрузка из iOS зависает на «ромашке».** Перезапускай только кнопкой питания.
- **Заряд в iOS не настоящий:** значок всегда показывает 100%. Настоящий уровень виден в OrangeFox. Там телефон
  заряжается, а заряжается ли он в iOS, не проверено.
- **Не перепрошивай `userdata`.** Metal, Sileo, утилиты и настройки сети пока есть только на телефоне, в
  `research/spes-ios-root.img` их нет.
- **Не делай `apt upgrade`:** обновления на этом порте не проверены. Отдельные пакеты ставь через
  `apt install ИМЯ`.
- **Что пока не работает:** Safari и Sileo показывают только обои, в интерфейсе есть артефакты, нет звука.

## Если что-то пошло не так

- **`fastboot` не отвечает:** держи питание 10–15 секунд и снова зайди в FASTBOOT.
- **Нет SSH:** проверь `ping 192.168.7.2`. Если сеть не поднялась, посмотри `nmcli dev` (профиль
  `ios-spes-usb` настраивает адрес `192.168.7.1` сам).
- **После перепрошивки `userdata`:** первая загрузка идёт около 15 минут, это нормально.

## Откат на Android

Заливать только этот пакет (модель `spesn`, регион EEA):

```
spesn_eea_global_images_OS1.0.11.0.TGKEUXM_20250324.0000.00_13.0_eea_aa692107e0.tgz
```

Он лежит в `research/rollback/`. Распакуй его и запусти `flash_all.sh`, **не `flash_all_lock.sh`**: второй заблокирует
загрузчик. Данные Android при этом не вернутся. Бэкапы разделов лежат в `/home/ruslan/spes-backup`, свежие копии
`persist` и `modemst` в подпапке `extra-20261105`.
